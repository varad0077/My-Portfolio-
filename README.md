👉 **[Experience Live Site](https://varads-portfolio.onrender.com)**

---

## ✨ Key Features & Highlights

- **🌸 Interactive Canvas Physics (`GhibliCanvas.jsx`)**:
  - 25 glowing fireflies with radial light halos and soft pulsing effects.
  - 8 floating leaves with vein rendering, rotation, and realistic wind drift physics.
  - Interactive mouse repulsion with smooth linear interpolation.
  - Animated Susuwatari soot sprites and Kodama tree spirits.

- **🎵 Web Audio Synthesizer (`AudioPlayer.jsx`)**:
  - Built-in ambient chime generator using native Web Audio API oscillators.

- **📜 Scroll-Triggered Reveal Animations (`ScrollReveal.jsx`)**:
  - `IntersectionObserver` scroll-reveal system applied across all portfolio sections.

- **🚀 Interactive Case Studies (`ProjectModal.jsx`)**:
  - Detailed project inspector modals with architecture notes, tech stacks, and live links.

- **⚡ Animated Hero Section (`Hero.jsx`)**:
  - Staggered word-by-word headline reveal and animated stat counters.

## 🛠️ Built With

- **Frontend**: React 19, JavaScript (ES6+)
- **Build Tool**: Vite 8
- **Icons**: Lucide React
- **Effects**: Canvas Confetti, HTML5 Canvas API, Web Audio API
- **Deployment**: Render Static Site (Auto-deploy via GitHub integration)

## 💻 Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/varad0077/My-Portfolio-.git

# 2. Navigate to project directory
cd My-Portfolio-

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```
